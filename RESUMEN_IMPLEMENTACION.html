🚀 Instalación Paso a Paso
  1. Copiar archivos
    cp useAlbumTracks.ts src/hooks/ cp EnhancedMusicPlayer.tsx src/components/ cp YoutubePlaylistImporter.tsx src/components/
  2. Reemplazar ruta principal

    Edita src/routes/index.tsx e importa EnhancedMusicPlayer

  3. Configurar APIs (Opcional)

    Crea variables de entorno para YouTube y Spotify API keys

  4. Probar localmente
    npm run dev # o bun dev
  5. Desplegar a producción
    npm run build # o bun build
🔒 Consideraciones de Seguridad
⚠️ IMPORTANTE: Nunca compartas tu API Key o Access Token en código público.

Usar variables de entorno:

# .env VITE_YOUTUBE_API_KEY=your_key_here VITE_SPOTIFY_ACCESS_TOKEN=your_token_here
💡 Tip: En producción, obtén los tokens desde tu backend, no desde el cliente.
📺 Configurar YouTube
  1. Ve a Google Cloud Console
  2. Crea un proyecto nuevo
  3. Habilita YouTube Data API v3
  4. Crea una API Key
  5. Copia tu Playlist ID
✓ La Opción 2 (URL individual) funciona sin API Key
🎵 Configurar Spotify
  1. Ve a Spotify Developer Dashboard
  2. Crea una aplicación
  3. Usa OAuth 2.0 para obtener token
  4. Obtén Album ID
  5. ¡Listo para usar!
✓ Obtiene metadatos completos (duración, artista, etc.)
💻 Ejemplos de Uso

Agregar canción manualmente:

const { addTrack } = useAlbumTracks(); addTrack({ id: 'custom-001', title: 'Mi Canción', url: 'https://example.com/song.mp3', artist: 'Mi Artista', });

Importar desde YouTube:

const { fetchFromYouTube } = useAlbumTracks(); fetchFromYouTube('PLxxxxxxxxxxx', 'YOUR_API_KEY');

Importar desde Spotify:

const { fetchFromSpotify } = useAlbumTracks(); fetchFromSpotify('4cOdK2wGLETKBW3PvgPWqL', 'ACCESS_TOKEN');
🐛 Solución de Problemas

Las canciones no se reproducen

  • Verifica que la URL sea válida
  • Comprueba CORS en la consola
  • Para YouTube, usa URLs incrustadas

API Key no funciona

  • Verifica que YouTube Data API esté habilitada
  • Comprueba el Playlist ID
  • Revisa cuota en Google Cloud Console

Canciones no se guardan

  • Verifica que localStorage esté habilitado
  • Comprueba espacio disponible (~5MB)
  • Abre la consola para errores
